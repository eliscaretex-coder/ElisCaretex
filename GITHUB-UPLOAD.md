# Upload pelo navegador do GitHub

Esta cópia foi preparada para envio ao GitHub sem a configuração local do Supabase.

## Importante

O arquivo abaixo contém apenas valores de exemplo:

`frontend/assets/js/config.js`

A Project URL e a Publishable key reais continuam somente na cópia local que
está rodando no seu computador.

## Estrutura esperada na raiz do repositório

```text
docs/
frontend/
supabase/
.gitignore
README.md
```

Não envie o arquivo ZIP diretamente. Extraia-o e envie o conteúdo da pasta.
